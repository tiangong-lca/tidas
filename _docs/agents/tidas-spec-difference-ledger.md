## W6b/A09 website schema convergence

The machine-readable report is [`tidas-spec-difference-ledger.json`](./tidas-spec-difference-ledger.json), generated by `scripts/ci/compare-tidas-spec.mjs` from one explicit `tidas-spec` source tree. It compares parsed JSON Schema structures and records every differing JSON pointer, category, and abbreviated value/hash. `oneOf`/`anyOf`/`allOf`, `required`, and `enum` are compared with stable identities or set semantics so taxonomy insertion does not create positional noise. The report is resolved only because every normative website asset now matches the selected candidate; the retained viewer projection remains explicitly non-normative.

## Reproduction

From the website repository root:

```bash
node scripts/ci/compare-tidas-spec.mjs \
  --spec-root ../tidas-spec \
  --site-commit 2b46fe5eb6ad16d43ee90a1b739113470c1658c0 \
  --check _docs/agents/tidas-spec-difference-ledger.json
```

The comparator fails if the selected source tree, file set, parsed content, or report metadata changes. The sync gate is the write/check entrypoint:

```bash
node scripts/ci/test-sync-tidas-spec.mjs
node scripts/ci/sync-tidas-spec.mjs \
  --spec-root ../tidas-spec \
  --spec-commit 6fb497bad562125ccc0c00a803351207b9ed438f \
  --check
```

The sync gate fails closed on invalid or missing manifest identity, unexpected files, missing normative files, hash drift, source identity drift, or an unbound viewer projection. It never changes the versioned `/spec/0.1.0` output.
