TIDAS Schema 用 JSON Schema 描述生命周期评估（LCA）的数据对象、分类词表和共享类型。它沿用多项 ILCD 概念与命名，便于在 JSON 工作流中表达相关数据；具体数据是否兼容 ILCD/eILCD，仍取决于所用 profile、字段值以及转换和校验结果。仅通过 JSON Schema 校验，不等于完成 ILCD/eILCD 符合性或往返转换证明。

> [在本站仓库查看和下载公开的 TIDAS JSON Schema 文件](https://github.com/tiangong-lca/tidas/tree/main/public/schemas)

公开目录包含 18 个逻辑合同 Schema：8 个数据集对象、9 个分类词表和 1 个共享类型文件；另有 1 个由共享类型派生的查看器投影。该投影只服务文档展示，不得用于校验或符合性证明。清单中的角色与数量由仓库内的机器可读 inventory 管理；与工具锁文件同名不表示内容逐字或结构完全一致。

## 技术边界

- **结构合同**：JSON Schema 定义字段类型、层级、引用和可自动执行的结构约束。
- **模块组合**：对象 Schema 引用共享类型和分类词表；消费方应从目标对象的根 Schema 开始解析引用。
- **诊断与符合性分离**：`tidas validate --schema-only` 只执行 Schema 层诊断，不证明 eILCD 可转换性；需要符合性结论时，应运行适用 profile 的完整 `tidas validate`，并在需要交换格式时执行实际转换检查。
- **版本可观察**：工具发布以 [`tidas-tools` Releases](https://github.com/tiangong-lca/tidas-tools/releases/latest) 为准。运行 `tidas version --format json` 可核对当前二进制版本、合同 Schema 和内嵌资产指纹。
