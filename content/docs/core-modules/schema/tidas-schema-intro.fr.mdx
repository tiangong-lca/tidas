TIDAS Schema utilise JSON Schema pour décrire les objets de jeu de données, les vocabulaires de classification et les types partagés de l’analyse du cycle de vie (ACV). Il reprend des concepts et noms ILCD pertinents pour les flux JSON. La compatibilité d’un jeu de données avec ILCD/eILCD dépend toutefois du profil choisi, des valeurs des champs et des résultats de conversion et de validation. Une validation JSON Schema réussie ne prouve ni la conformité ILCD/eILCD ni une conversion aller-retour.

> [Parcourir et télécharger les fichiers TIDAS JSON Schema publiés depuis le dépôt de ce site](https://github.com/tiangong-lca/tidas/tree/main/public/schemas)

Le répertoire public contient 18 schémas de contrat logiques : 8 objets de jeu de données, 9 vocabulaires de classification et 1 fichier de types partagés. Une dix-neuvième ressource JSON est une projection dérivée de ces types pour l’explorateur. Elle sert uniquement à la présentation et ne doit pas être utilisée pour la validation ou une preuve de conformité. Un nom identique dans le verrouillage des outils ne garantit pas une parité structurelle ou octet par octet.

## Limite technique

- **Contrats structurels** : JSON Schema définit les types de champs, la hiérarchie, les références et les contraintes structurelles exécutables.
- **Composition modulaire** : les schémas d’objets référencent les types partagés et les vocabulaires de classification ; les consommateurs doivent résoudre les références depuis le schéma racine choisi.
- **Le diagnostic n’est pas la conformité** : `tidas validate --schema-only` exécute uniquement le diagnostic au niveau Schema et ne prouve pas la convertibilité eILCD. Une conclusion de conformité requiert l’exécution complète de `tidas validate` avec le profil applicable et, si un format d’échange est requis, un essai de conversion réel.
- **Version observable** : les [`tidas-tools` Releases](https://github.com/tiangong-lca/tidas-tools/releases/latest) font autorité pour les publications. `tidas version --format json` permet d’inspecter la version binaire installée, les schémas de contrat et les empreintes des ressources intégrées.
