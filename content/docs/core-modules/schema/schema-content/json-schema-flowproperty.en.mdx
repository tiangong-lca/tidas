## JSON Schema for Flow Property and Flow Property Category

<Callout type="idea">
Flow properties define the measurement basis for flows—such as mass, volume, or energy. They establish how quantities are expressed and linked to unit groups, enabling accurate quantification and comparison of flows across datasets.
