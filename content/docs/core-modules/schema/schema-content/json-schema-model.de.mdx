## JSON Schema für Lebenszyklusmodelle

<Callout type="idea">
Ein Lebenszyklusmodell ist ein System miteinander verbundener Prozesse, die gemeinsam den vollständigen oder einen Teil des Lebenszyklus eines Produktsystems abbilden. Der letzte Prozessschritt („Referenzprozessinstanz“) wird vom Datensatz des Lebenszyklusmodells referenziert; über die verbindenden Produkt- und Abfallflüsse werden alle weiteren Prozessinstanzen verknüpft und schrittweise skaliert.
</Callout>
