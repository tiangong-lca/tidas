## JSON Schema pour les Contacts et la catégorie Contacts

<Callout type="idea">
Le jeu de données de contact comprend des informations sur les personnes, organisations, groupes de travail ou réseaux de bases de données associés à un jeu de données. Il inclut généralement des noms, adresses, numéros de téléphone et e-mails, facilitant la communication et la gouvernance des données.
</Callout>
