## JSON Schema für Methoden und Kategorien der Wirkungsabschätzung (LCIA)

<Callout type="idea">
Der Datensatz einer Methode zur Wirkungsabschätzung (LCIA) enthält Charakterisierungsfaktoren und Wirkungskategorien zur Bewertung von Umweltwirkungen. Er stellt den methodischen Hintergrund und die Dokumentation bereit, die für die Anwendung der LCIA in Ökobilanzstudien erforderlich sind.
</Callout>
