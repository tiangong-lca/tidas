## JSON Schema für Flusseigenschaften und ihre Kategorien

<Callout type="idea">
Flusseigenschaften legen die Messbasis eines Flusses fest, etwa Masse, Volumen oder Energie. Sie bestimmen, wie Mengen ausgedrückt und mit Einheitengruppen verknüpft werden. Dadurch lassen sich Flüsse datensatzübergreifend präzise quantifizieren und vergleichen.
</Callout>
