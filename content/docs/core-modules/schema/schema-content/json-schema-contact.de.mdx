## JSON Schema für Kontakte und Kontaktkategorien

<Callout type="idea">
Der Kontaktdatensatz enthält Angaben zu Personen, Organisationen, Arbeitsgruppen oder Datenbanknetzwerken, die mit einem Datensatz verbunden sind. Dazu gehören in der Regel Namen, Anschriften, Telefonnummern und E-Mail-Adressen. Diese Informationen unterstützen die Kommunikation und Data Governance.
</Callout>
