## JSON Schema pour le Modèle de cycle de vie

<Callout type="idea">
Système de processus interconnectés représentant conjointement le cycle de vie complet ou partiel d'un système de produits, l'étape de processus finale (« Instance de processus de référence ») étant référencée à partir de ce jeu de données de modèle de cycle de vie, qui connecte et met à l'échelle de manière progressive toutes les autres instances de processus via les échanges de produits et de déchets de connexion.
</Callout>
