## JSON Schema für Einheitengruppen und ihre Kategorien

<Callout type="idea">
Eine Einheitengruppe definiert zusammengehörige Maßeinheiten und ihre Umrechnungsfaktoren. Sie unterstützt die Definition von Flusseigenschaften und gewährleistet konsistente Einheitenumrechnungen innerhalb eines Datensatzes und über Datensätze hinweg.
</Callout>
