## 流及流分类的数据结构

<Callout type="idea">
流数据集定义了生命周期评估中使用的物质、能量或废弃物，​并描述了它的名称、分类、流属性等信息，是构建过程和系统数据集的基础，确保了数据的一致性和可追溯性。
</Callout>

## 产品/废物流分类（Product / Waste Flows category）

本页采用 **CPC Version 3.0**，依据[联合国统计司的 2025-06-30 分类结构](https://unstats.un.org/unsd/classifications/Econ/CPC)，共 4,586 个节点，保留官方英文名称。沿完整父子路径选择适用的最细分类。历史数据的旧分类须保留其来源版本并另行核对映射，不能只修改版本标注就视为完成迁移。CPC 版本与 TIDAS Schema 或工具版本分别记录。 联合国统计司已提供该分类结构，联合国正式出版物仍标注为即将出版。
