## JSON Schema pour les Propriétés de flux et la catégorie Propriétés de flux

<Callout type="idea">
Les propriétés de flux définissent la base de mesure des flux — telle que la masse, le volume ou l'énergie. Elles établissent la manière dont les quantités sont exprimées et liées aux groupes d'unités, permettant une quantification et une comparaison précises des flux entre les jeux de données.
</Callout>
