模型（Model）、过程（Process）和流（Flow）是相互补充的三类核心数据。流说明交换的是什么，过程记录输入输出清单，模型组织过程实例及其连接。既可以用已有过程建立模型，也可以在后续模型中复用保存好的结果过程。

## 三类核心数据

| 对象 | 记录什么 | 怎样关联 |
| --- | --- | --- |
| **模型** | 产品系统中的过程实例、连接和参考目标 | 实例引用特定版本的过程；模型可引用由它生成的结果过程 |
| **过程** | 指定参考尺度下的输入输出清单及其文档 | 通过交换引用流；既可作为模型组件，也可承载汇总后的清单 |
| **流** | 产品、物质、能量或废物的身份、分类和计量属性 | 被过程交换引用，并用于识别模型中连接的流 |

**过程不限于单元过程。** 过程数据集也可以描述汇总后的生命周期清单或部分终止系统。模型保留过程之间的结构，结果过程提供可继续引用的清单。

## 结构中的引用怎样读取

下表列出字段的引用方向。关系图中的灰色实线表示过程引用流，紫色实线表示组成、计算与复用，虚线表示来源回溯。过程实例和交换属于数据集内部结构，不能都理解成独立数据集。

| 引用关系 | 对应字段或含义 |
| --- | --- |
| 模型 → 过程 | `processInstance.referenceToProcess` 引用过程及其版本；模型连接记录实例之间的交换连接 |
| 模型 → 结果过程 | `referenceToResultingProcess` 引用由模型生成的 LCI 结果或部分终止系统过程数据集 |
| 过程 → 交换 → 流 | `exchanges.exchange[].referenceToFlowDataSet` 引用输入或输出使用的流数据集 |
| 流 → 流属性 | `referenceToFlowPropertyDataSet` 引用质量、能量、体积等计量属性 |
| 流属性 → 单位组 | `referenceToReferenceUnitGroup` 引用相关单位组及其参考单位 |

流定义**交换的是什么**；交换记录**方向和数量**。不同过程可以引用同一个流，并记录不同的输入或输出数量。产品流用于技术系统内的产品、材料或能量交换；废物流用于后续处理；基本流表示技术系统与自然环境之间的资源取用或排放。

过程中的 `referenceToReferenceFlow` 使用本过程交换的内部编号，选出参考交换；它不是另一个流数据集的 UUID。模型参考的过程实例、过程的参考交换和流的参考计量属性也各有作用。

复用数据时，应核对身份、确切版本和计量依据，并判断地域、时间和技术是否适合研究。名称相同不能代替这些检查。

## 从过程到模型，再复用结果过程

1. 选择已有过程的具体版本，将它们作为模型实例，并连接相应输入和输出。
2. 明确参考过程、参考交换和目标数量，定义计算需求。
3. 计算该目标下的汇总输入输出清单，并在所用软件支持的工作流中保存为结果过程。
4. 在下一个模型中引用这个结果过程，继续构建更大的产品系统。

一个模型可能对应主结果和其他产品结果；复用前检查所选结果的参考产品、数量和系统边界。**汇总清单本身不能重建缺失的原始模型图。** 要追溯构成过程和连接，需要保留源模型及其引用的数据。

这里解释数据关系和复用途径。计算何时执行、如何保存和更新结果，由消费软件定义。天工 LCA 平台当前的操作见[模型保存与结果复用](https://docs.tiangong.earth/zh/docs/overview/data-relationships/)。模型结构本身不保证一次保存会自动执行上述全部步骤。

### 一个简化的铝板例子

铝板模型引用电力、原铝和轧制过程，通过电力、铝等流连接。以 **1 kg 铝板**为参考目标计算，并将汇总输入输出清单保存为铝板结果过程。汽车模型随后可按所需铝板数量引用该结果过程。

铝板流标识交换的对象；铝板过程提供清单；源模型保留形成清单的过程结构。复用时检查结果边界已包含哪些活动，避免再添加相同活动造成重复计算。此例只说明关系，不是经验证的生产数据。

## 计量、证据与责任

| 支持数据 | 作用 |
| --- | --- |
| **流属性** | 定义质量、能量或体积等计量依据，并引用单位组 |
| **单位组** | 定义相关单位和换算系数，例如 kg 与 g |
| **来源** | 记录文献、报告及其他依据，可由数据集或具体交换引用 |
| **联系人** | 记录人员、组织及编制、录入、所有权等责任 |

来源和联系人支持解释与追溯，不能当作产品系统中的物理流连接。图中的支持信息带与计量引用链分开表示。

## 清单、影响评价与规范边界

生命周期清单（LCI）是输入输出及其数量；生命周期影响评价（LCIA）将相关基本流映射为潜在环境影响指标。保存了清单，不等于每个影响类别都有完整的表征因子覆盖；单个碳足迹数值也不能代替可复用的输入输出清单。
