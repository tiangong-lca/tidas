This site explains the TIDAS specification; the unified `tidas` CLI in `tidas-tools` owns executable behavior. Start by running `tidas version --format json` so the binary, contract, asset, and runtime fingerprints travel with validation or conversion evidence.

This section covers installation, command boundaries, and migration. Treat [tidas-tools Releases](https://github.com/tiangong-lca/tidas-tools/releases/latest) as the authority for the current release and installation assets instead of copying a release number into long-lived documentation.
