Les outils en ligne de commande TIDAS sont maintenant distribués comme un seul exécutable Rust multi-plateforme nommé `tidas`. La version stable actuelle est [`v0.1.1`](https://github.com/tiangong-lca/tidas-tools/releases/tag/v0.1.1). Il ne nécessite pas Python, Java, Node.js, Homebrew ou vcpkg à l'exécution.

---

## 🔍 Vue d'ensemble des commandes

- `tidas validate` valide le JSON TIDAS ou le XML ILCD hors ligne et peut écrire un flux déterministe de problèmes JSONL.

- `tidas convert` convertit bidirectionnellement entre le JSON TIDAS et le XML eILCD.

- `tidas import` importe EcoSpold 1/2, SimaPro CSV, openLCA JSON-LD, openLCA process XLSX ou ILCD.

- `tidas export` crée un ZIP TIDAS/ILCD déterministe à partir des enregistrements de base de données et du stockage d'objets optionnel.

- `tidas release` valide, convertit et construit des paquets de version reproductibles.

- `tidas ruleset` inspecte les ensembles de règles empaquetés avec l'exécutable.

- `tidas version` rapporte les empreintes binaires, de contrat, d'actifs et d'exécution.

Chaque commande produit est implémentée en Rust et prend en charge des options destinées à l'automatisation, telles que `--format json`, `--report` et des limites configurables de mémoire et de file d'attente.

## 🚀 Installer v0.1.1

Les archives de versions GitHub préconstruites sont le canal utilisateur final recommandé. Les cibles supportées sont Linux x86_64/ARM64, macOS Intel/Apple Silicon et Windows x86_64. Windows ARM64 n'est pas supporté.

macOS/Linux :

```bash
curl --proto '=https' --tlsv1.2 -fsSLO \
  https://github.com/tiangong-lca/tidas-tools/releases/download/v0.1.1/install.sh
sh install.sh --version 0.1.1 --prefix "$HOME/.local"
```

Windows PowerShell :

```powershell
Invoke-WebRequest `
  https://github.com/tiangong-lca/tidas-tools/releases/download/v0.1.1/install.ps1 `
  -OutFile install.ps1
.\install.ps1 -Version 0.1.1
```

Les installateurs sélectionnent l'archive de plateforme et vérifient son empreinte SHA-256. Vous pouvez également télécharger une archive et `SHA256SUMS` directement depuis la [version v0.1.1](https://github.com/tiangong-lca/tidas-tools/releases/tag/v0.1.1). La formule Homebrew jointe et les manifestes Winget lient les mêmes empreintes d'archive, mais n'impliquent pas qu'un tap externe ou une soumission Winget Community soit en ligne.

Les développeurs avec Rust 1.88+ et les dépendances de développement libxml2/libxslt de plateforme peuvent installer depuis crates.io :

```bash
cargo install tidas --version 0.1.1 --locked
```

## ⚡ Exemples rapides

```bash
tidas version --format json
tidas validate ./tidas-package --issues ./issues.jsonl --format json
tidas convert ./tidas-package --output ./eilcd-package --to ilcd --format json
tidas convert ./eilcd-data --output ./tidas-package --to tidas --format json
tidas import ./database.zip --output ./imported --target both --format json
```

La CLI intègre et vérifie l'intégrité des ressources JSON Schema, XSD, XSLT et méthodologiques dont elle a besoin. L'utilisation normale ne nécessite pas de copier des ressources depuis les anciens répertoires source. La conversion matérialise les ressources cibles verrouillées dans son paquet de sortie.

## Migrer depuis les commandes héritées

Les anciens exécutables autonomes et la disposition des arguments de package Python ne sont plus le chemin actif documenté par ce site :

| Point d'entrée hérité | Point d'entrée v0.1.1 |
| --- | --- |
| `tidas-validate` / `validation.py` | `tidas validate` |
| `tidas-convert` | `tidas convert` |
| `tidas-import` | `tidas import` |
| `tidas-export` | `tidas export` |

La disposition des arguments a également changé. Les entrées sont généralement positionnelles, les sorties utilisent `--output`, et la direction de conversion utilise `--to ilcd|tidas`. Exécutez `tidas <command> --help` avant de migrer l'automatisation au lieu de transmettre les anciennes options.
