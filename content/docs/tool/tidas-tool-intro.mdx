TIDAS 命令行工具以单个跨平台 Rust 可执行文件 `tidas` 发布。本站说明命令的稳定语义，具体版本、平台归档、校验和与安装前提则以
[GitHub Latest Release](https://github.com/tiangong-lca/tidas-tools/releases/latest)
为权威来源，避免文档中的版本号与实际发布脱节。

---

## 🚀 获取与核对版本

终端用户应从 Latest Release 选择与操作系统和架构匹配的预编译归档，并按照同一 Release
中的说明核对 `SHA256SUMS`。Release 附带的 Homebrew formula 或 Winget manifest
只描述对应归档及哈希；外部 tap 或 Winget Community 是否可用，仍需以发布说明为准。

需要从 crates.io 安装的开发者，应先确认 Release 中声明的 Rust 与原生依赖要求，再使用从
Releases 页面取得的版本号：

```bash
# 从 Releases/latest 复制版本号，并去掉可能存在的前导 v
TIDAS_VERSION="<release-version>"
cargo install tidas --version "$TIDAS_VERSION" --locked
```

安装后不要根据文件名推断版本。直接检查正在运行的二进制及其内嵌资源指纹：

```bash
tidas version --format json
```

该输出是确认实际 CLI 版本、契约版本以及 Schema、XSD、XSLT 和方法学资源指纹的首选依据。

## 🔍 七个统一子命令

- `tidas convert`：在受支持的 TIDAS JSON 与 eILCD XML 路径之间转换。

- `tidas import`：把 EcoSpold、SimaPro、openLCA 或 ILCD 等受支持来源导入统一流程。

- `tidas export`：从数据库记录和可选对象存储生成确定性的 TIDAS/ILCD ZIP。

- `tidas validate`：离线校验 TIDAS JSON 或 ILCD XML，并可输出确定性的 JSONL 问题清单。

- `tidas release`：验证、转换并构建可复现的发布包。

- `tidas ruleset`：检查随二进制发布的规则集。

- `tidas version`：输出二进制、契约、资源和运行时指纹。

各子命令的当前参数以 `tidas <command> --help` 为准；用于自动化时优先采用命令支持的
`--format json`、报告文件和资源上限选项。

## ✅ 理解校验层级

`--schema-only` 只用于定位结构层面的 Schema 问题。它不是完整一致性校验，也不能证明数据
一定可以转换成 eILCD。交付前应先运行普通 `validate`，并在目标工作流要求 eILCD 时实际执行
适用的转换路径：

```bash
tidas validate ./tidas-package --schema-only --format json
tidas validate ./tidas-package --issues ./issues.jsonl --format json
tidas convert ./tidas-package --output ./eilcd-package --to ilcd --format json
```

其他常见入口：

```bash
tidas convert ./eilcd-data --output ./tidas-package --to tidas --format json
tidas import ./database.zip --output ./imported --target both --format json
```

CLI 会内嵌并校验运行所需的 JSON Schema、XSD、XSLT 和方法学资源；通常不需要从旧源码目录
手工复制资源。对于审计或复现，请保留 `tidas version --format json` 的指纹输出。

## 从旧命令迁移

旧的独立可执行文件和 Python 包参数不再是本站的活动使用路径：

| 旧入口 | 统一 CLI 入口 |
| --- | --- |
| `tidas-validate` / `validation.py` | `tidas validate` |
| `tidas-convert` | `tidas convert` |
| `tidas-import` | `tidas import` |
| `tidas-export` | `tidas export` |

输入通常是位置参数，输出使用 `--output`，转换方向使用 `--to ilcd|tidas`。迁移自动化前请逐条
查看 `tidas <command> --help`，不要直接沿用旧参数。
