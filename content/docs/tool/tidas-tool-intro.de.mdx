Die TIDAS-Kommandozeilenwerkzeuge werden als eine plattformübergreifende,
in Rust entwickelte ausführbare Datei namens `tidas` bereitgestellt. Die aktuelle
stabile Version ist [`v0.1.1`](https://github.com/tiangong-lca/tidas-tools/releases/tag/v0.1.1).
Zur Laufzeit sind weder Python, Java, Node.js, Homebrew noch vcpkg erforderlich.

---

## 🔍 Befehlsübersicht

- `tidas validate` prüft TIDAS-JSON oder ILCD-XML offline und kann einen deterministischen JSONL-Problemstrom schreiben.

- `tidas convert` konvertiert in beide Richtungen zwischen TIDAS-JSON und eILCD-XML.

- `tidas import` importiert EcoSpold 1/2, SimaPro CSV, openLCA JSON-LD, openLCA Process XLSX oder ILCD.

- `tidas export` erzeugt aus Datenbankeinträgen und optionalem Objektspeicher ein deterministisches TIDAS-/ILCD-ZIP.

- `tidas release` prüft und konvertiert Daten und erstellt reproduzierbare Veröffentlichungspakete.

- `tidas ruleset` zeigt die mit dem Programm ausgelieferten Regelsätze an.

- `tidas version` gibt Fingerabdrücke von Binärdatei, Vertrag, Assets und Laufzeit aus.

Alle Produktbefehle sind in Rust implementiert und unterstützen Optionen für die
Automatisierung, darunter `--format json`, `--report` sowie begrenzbare Speicher-
und Warteschlangensteuerungen.

## 🚀 Version 0.1.1 installieren

Für Endanwender werden die vorgefertigten Archive der GitHub-Veröffentlichung
empfohlen. Unterstützt werden Linux x86_64/ARM64, macOS auf Intel/Apple Silicon
und Windows x86_64. Windows ARM64 wird nicht unterstützt.

macOS/Linux:

```bash
curl --proto '=https' --tlsv1.2 -fsSLO \
  https://github.com/tiangong-lca/tidas-tools/releases/download/v0.1.1/install.sh
sh install.sh --version 0.1.1 --prefix "$HOME/.local"
```

Windows PowerShell:

```powershell
Invoke-WebRequest `
  https://github.com/tiangong-lca/tidas-tools/releases/download/v0.1.1/install.ps1 `
  -OutFile install.ps1
.\install.ps1 -Version 0.1.1
```

Die Installationsskripte wählen das passende Plattformarchiv und prüfen dessen
SHA-256-Prüfsumme. Archiv und `SHA256SUMS` können auch direkt aus der
[Veröffentlichung v0.1.1](https://github.com/tiangong-lca/tidas-tools/releases/tag/v0.1.1)
geladen werden. Die beigefügte Homebrew-Formel und die Winget-Manifeste binden
dieselben Archiv-Hashes; daraus folgt jedoch nicht, dass bereits ein externer
Tap oder eine Winget-Community-Einreichung verfügbar ist.

Entwickler mit Rust 1.88+ und den plattformspezifischen
libxml2-/libxslt-Entwicklungsabhängigkeiten können über crates.io installieren:

```bash
cargo install tidas --version 0.1.1 --locked
```

## ⚡ Kurze Beispiele

```bash
tidas version --format json
tidas validate ./tidas-package --issues ./issues.jsonl --format json
tidas convert ./tidas-package --output ./eilcd-package --to ilcd --format json
tidas convert ./eilcd-data --output ./tidas-package --to tidas --format json
tidas import ./database.zip --output ./imported --target both --format json
```

Die CLI enthält die benötigten JSON-Schema-, XSD-, XSLT- und Methodik-Assets und
prüft deren Integrität. Bei normaler Verwendung müssen keine Assets aus alten
Quellverzeichnissen kopiert werden. Die Konvertierung legt die gesperrten
Ziel-Assets im Ausgabepaket ab.

## Von früheren Befehlen migrieren

Die früheren Einzelprogramme und das Argumentlayout des Python-Pakets sind nicht
mehr der von dieser Dokumentation unterstützte Weg:

| Früherer Einstiegspunkt | Einstiegspunkt in v0.1.1 |
| --- | --- |
| `tidas-validate` / `validation.py` | `tidas validate` |
| `tidas-convert` | `tidas convert` |
| `tidas-import` | `tidas import` |
| `tidas-export` | `tidas export` |

Auch das Argumentlayout hat sich geändert. Eingaben sind meist positionsgebunden,
Ausgaben verwenden `--output`, und die Konvertierungsrichtung wird mit
`--to ilcd|tidas` festgelegt. Prüfen Sie vor der Migration einer Automatisierung
`tidas <command> --help`, statt alte Optionen unverändert zu übernehmen.
