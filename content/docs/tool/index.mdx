TIDAS 规范本身由本站解释，可执行行为由 `tidas-tools` 中的统一 `tidas` CLI 实现。建议先用 `tidas version --format json` 记录当前二进制、合同、资产和运行时指纹，再把同一份证据与校验或转换结果一起保存。

本节介绍安装、命令边界和迁移路线。最新版本和安装资产以 [tidas-tools Releases](https://github.com/tiangong-lca/tidas-tools/releases/latest) 为准，页面不复制会随发布变化的版本号。
