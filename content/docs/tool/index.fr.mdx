title: "Outils TIDAS : contrôler, convertir et empaqueter les données"

---

`tidas` est un programme en ligne de commande qui s’exécute dans un terminal. Il peut contrôler les champs et les références des fichiers TIDAS, convertir entre TIDAS et eILCD lorsque cette conversion est prise en charge, puis aider à importer, exporter et préparer des paquets de données à livrer.

L’outil contrôle la structure des fichiers et les règles mises en œuvre. Il ne choisit pas l’unité fonctionnelle, la frontière du système ou la méthode d’allocation, ne juge pas si la qualité des données est suffisante et ne remplace pas une revue critique indépendante. La version courante et les fichiers d’installation se trouvent dans la [dernière version de tidas-tools](https://github.com/tiangong-lca/tidas-tools/releases/latest). Après l’installation, `tidas --help` présente les points de départ.

## Pour aller plus loin : consigner la version de l’outil

Si votre équipe doit reproduire plus tard un contrôle ou une conversion, exécutez :

```bash
tidas version --format json
```

Cette commande indique les versions de l’outil et des règles associées dans un format facile à conserver. Gardez sa sortie avec le rapport de contrôle ou le résultat de conversion afin d’identifier la version utilisée. Ce détail technique n’est pas nécessaire pour une première lecture ou un premier essai.
