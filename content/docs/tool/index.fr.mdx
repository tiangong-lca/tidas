Ce site explique la spécification TIDAS ; la CLI unifiée `tidas` de `tidas-tools` définit le comportement exécutable. Commencez par `tidas version --format json` afin de conserver les empreintes du binaire, du contrat, des ressources et de l’exécution avec les preuves de validation ou de conversion.

Cette section couvre l’installation, les limites des commandes et la migration. Les [versions de tidas-tools](https://github.com/tiangong-lca/tidas-tools/releases/latest) constituent la source pour la version courante et les ressources d’installation ; la documentation durable ne recopie pas un numéro de version susceptible de changer.
