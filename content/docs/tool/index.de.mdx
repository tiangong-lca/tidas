Diese Website erklärt die TIDAS-Spezifikation; das einheitliche `tidas`-CLI in `tidas-tools` definiert das ausführbare Verhalten. Führen Sie zuerst `tidas version --format json` aus, damit Fingerabdrücke von Binärdatei, Vertrag, Assets und Laufzeit zusammen mit Prüf- oder Konvertierungsnachweisen gespeichert werden.

Dieser Abschnitt beschreibt Installation, Befehlsgrenzen und Migration. Die [tidas-tools-Veröffentlichungen](https://github.com/tiangong-lca/tidas-tools/releases/latest) sind die Quelle für die aktuelle Version und Installationsdateien; langfristige Dokumentation kopiert keine veränderliche Versionsnummer.
