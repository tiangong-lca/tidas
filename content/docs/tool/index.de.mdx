`tidas` ist ein Kommandozeilenprogramm, das in einem Computerterminal ausgeführt wird. Es prüft Felder und Verweise in TIDAS-Dateien, konvertiert – soweit unterstützt – zwischen TIDAS und eILCD und hilft beim Import, Export und Erstellen übergabefertiger Datenpakete.

Das Werkzeug prüft Dateistruktur und implementierte Regeln. Es wählt weder funktionelle Einheit, Systemgrenze oder Allokationsmethode, noch beurteilt es eine ausreichende Datenqualität oder ersetzt eine unabhängige kritische Prüfung. Die aktuelle Version und Installationsdateien stehen auf der Seite der [neuesten tidas-tools-Veröffentlichung](https://github.com/tiangong-lca/tidas-tools/releases/latest). Nach der Installation zeigt `tidas --help` die verfügbaren Einstiege.

## Für Fortgeschrittene: Werkzeugversion festhalten

Soll eine Prüfung oder Konvertierung später reproduziert werden, führen Sie Folgendes aus:

```bash
tidas version --format json
```

Der Befehl listet die verwendeten Werkzeug- und Regelversionen in speicherbarer Form auf. Bewahren Sie die Ausgabe zusammen mit dem Prüfbericht oder Konvertierungsergebnis auf. Für das normale Lesen oder einen ersten Versuch ist dieses technische Detail nicht erforderlich.
