## Vue d'ensemble

L'intégration entre HiQ-Editor et TIDAS est significative car :

- Elle facilite les échanges de données ACV pour les utilisateurs tels que les entreprises, les institutions de recherche et les gouvernements, permettant des évaluations d'impact environnemental utilisant des données mondiales tout en assurant l'universalité et la comparabilité des données.

- Elle facilite l'interaction des données ACV (comme ELCD, HiQLCD) entre différentes plateformes, évitant les silos de données et améliorant l'interopérabilité.

- L'utilisation d'une structure de données unifiée et d'exigences de qualité rend les données ACV plus standardisées, transparentes et traçables, assurant l'intégrité et la cohérence des données tout en améliorant la fiabilité.

## Prérequis

- Permissions de compte TIDAS

- Connaissance de base du schéma TIDAS

- Permissions de compte HiQ-Editor

## Méthodes d'intégration de données

HiQ-Editor s'intègre principalement à TIDAS par :

1. Import/export au format ILCD pour prendre en charge le flux de données entre les systèmes

2. Interfaces API pour la révision et le transfert de données

## Étapes d'intégration

### Import/Export de données

1. Les utilisateurs (éditeurs) modifient les données dans HiQ-Editor.
![Modification des données dans HiQ-Editor](/img/use-case/block-builder-edit.png)

2. Les utilisateurs (gestionnaires) effectuent les calculs LCIA sur une version de données dans HiQ-Editor et la publient.

3. Les utilisateurs sélectionnent les données à exporter - le système analyse le schéma de données ACV de HiQ-Editor et exporte sous forme de document conforme ILCD.

4. Les utilisateurs importent et analysent le document ILCD dans le système TIDAS.
![Import d’un document ILCD dans TIDAS](/img/use-case/block-builder-import.png)

### Révision et transfert de données

1. Les utilisateurs (éditeurs) modifient les données dans HiQ-Editor et les soumettent pour révision.

2. HiQ-Editor établit une connexion API avec TIDAS pour vérifier les droits d'accès.

3. Les données soumises sont transmises à TIDAS pour révision via l'interface d'intégration.

4. Les utilisateurs (réviseurs) révisent et valident les données dans le système TIDAS, avec support pour renvoyer le contenu/résultats de la révision à HiQ-Editor.

## FAQ

### Q1 : Que faire si les données soumises depuis HiQ-Editor ne peuvent pas être transférées vers TIDAS ?

R : Vérifiez si les données dans HiQ-Editor ont passé la validation de complétude et leur statut de calcul - seules les données calculées peuvent être transférées à TIDAS pour révision.

### Q2 : Que faire si certaines informations de champ sont manquantes après l'export ?

R : L'export HiQ-Editor suit les normes de format ILCD - les champs spécifiques aux exigences métier personnalisées qui ne font pas partie des spécifications ILCD ne seront pas inclus dans l'export.
