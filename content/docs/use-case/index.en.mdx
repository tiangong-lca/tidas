Use cases explain how TIDAS data moves through a particular system; they do not create an additional normative layer. Record the data format, exchange boundary, authorization model, and tested component versions separately, and do not generalize one case into a guarantee for every platform.

Read the [Core Modules Overview](/en/docs/core-modules/) first, then map the case’s data objects and validation route to your own system.
