title: "集成概览"
description: "区分 TIDAS 互操作合同与可选的平台、可信计算和 AI 集成模式。"
---

集成的起点是可验证的 TIDAS 数据包：每个对象有稳定 ID，跨文档引用完整，交换方能记录合同和资产指纹。区块链、授权、隐私计算和 MCP AI 是基于这一基础的可选参考模式，不是 JSON Schema 合规的必要条件。

实施前请确认页面所声明的组件、信任边界和已验证范围是否适用于当前系统。天工 LCA 平台的用户操作路线见 [平台文档](https://docs.tiangong.earth/zh/docs/)。
