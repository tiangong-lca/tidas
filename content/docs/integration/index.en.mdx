description: "Separate the TIDAS interoperability contract from optional platform, trusted-computing, and AI patterns."
---

Integration starts with a verifiable TIDAS package: every object has a stable identifier, cross-document references are complete, and exchange partners can record the effective contract and asset fingerprints. Blockchain, authorization, privacy computing, and MCP AI are optional reference patterns built on that foundation; they are not prerequisites for JSON Schema conformance.

Before implementation, confirm that a page’s stated components, trust boundary, and tested scope fit the target system. User workflows for the TianGong LCA platform belong in the [platform documentation](https://docs.tiangong.earth/en/docs/).
