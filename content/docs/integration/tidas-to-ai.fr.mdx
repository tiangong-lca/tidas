Les services IA MCP (Model Context Protocol) sont des composants de moteur intelligent dans le système TIDAS qui améliorent les capacités de compréhension, de complétion et de validation des données de cycle de vie, conçus pour les scénarios de gestion et d'application intelligente des données environnementales de prochaine génération.

## ✨ Fonctionnalités principales

Les services MCP intègrent les capacités d'IA dans les bases de données de cycle de vie TIDAS, fournissant les fonctionnalités principales suivantes :

- **Recherche sémantique** : Interroger en langage naturel les flux d'inventaire du cycle de vie (« LCA Flows »)

- **Complétion intelligente** : Aider à compléter les champs manquants ou suggérer des améliorations structurelles

- **Validation de format** : Valider automatiquement la conformité des données sur la base du JSON Schema

- **Support de débogage et de validation** : Prend en charge le débogage et la validation des processus de service à l'aide de l'outil MCP Inspector (comme illustré ci-dessous)

## 🧱 Mise en œuvre technique

Les services MCP sont implémentés sur la base de :

- **Protocole de transport** : Prend en charge le service SSE avec WebSocket, HTTP et autres modes de transmission

- **Traitement des données** : Analyse et traite les données sur la base du format TIDAS (JSON Schema)

- **Ordonnancement des outils** : Intègre divers outils intelligents comme `Search_flows_Tool`

- **Déploiement local** : Prend en charge le déploiement privé pour garantir la sécurité et la conformité des données

## 🔗 Code source

Les services MCP sont publiés en open source sur GitHub :
👉 [https://github.com/linancn/tiangong-lca-mcp](https://github.com/linancn/tiangong-lca-mcp)

Le projet fournit le code serveur complet, un exemple de frontend (incluant des exemples d'intégration pour l'outil de débogage Inspector), la documentation d'enregistrement et de test des outils, permettant un développement rapide de plateformes de données de cycle de vie pilotées par l'IA basées sur l'architecture TIDAS.

## 📦 Prérequis

- Une base de données de cycle de vie conforme au [Schéma TIDAS](/fr/docs/core-modules/schema/tidas-schema-intro/) a été construite

- Le jeton Bearer MCP et l'adresse du service ont été configurés

- Les outils intelligents requis (par exemple Search_flows_Tool) ont été enregistrés selon les besoins

---

Pour intégrer davantage de services intelligents d'ACV ou construire votre propre plateforme de données fondée sur l'IA, les services MCP offrent un point de départ efficace.
