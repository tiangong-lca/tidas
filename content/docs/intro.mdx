**TIDAS**（**TI**angong **DA**ta **S**ystem）是一套开放的 LCA 数据结构和工具规则。它把过程、流、单位、来源及其相互引用按同一方式保存，让不同团队和软件更容易检查、转换和交换数据。

可以把 TIDAS 理解为 LCA 数据的“共同填写方式”。它帮助整理和检查数据，但不会替代研究目的、功能单位、系统边界、分配、数据质量和专业评审等 LCA 判断。

## 🧱 TIDAS 包含什么

TIDAS 架构由以下三部分组成：

### 📖 LCA 数据工作要求（Methodology）

- [LCA / 碳足迹数据库构建导则](https://www.carbonfootprint.network/docs/category/lca-database-guideline)
  说明建立和维护 LCA 数据库时需要记录的方法、质量和评审信息，并参考 ISO 14040/44、ILCD Handbook 与 ecoinvent 的相关实践。

### 🧾 数据填写与交换结构（Format）

- [TIDAS 数据结构](/zh/docs/core-modules/schema/tidas-schema-intro/)
  用 JSON 保存数据，并用 JSON Schema 检查必填字段、数据类型、取值和引用关系。

### 📦 参考数据（Data）

- [基础数据包](https://github.com/linancn/EF-reference-package-3.1-Correction)
  提供可复用的分类、单位和基础数据，帮助不同数据集使用一致的名称和编号。

---

## 🛠 辅助工具（Tools）

**TIDAS 工具**是在电脑终端中运行的命令行程序，用于检查文件、转换受支持的格式以及导出数据包。

- 🧪 `validate`：检查文件结构、必填字段和文件之间的引用

- 🔄 `convert`：在工具明确支持的规则范围内转换 TIDAS 与 eILCD 数据

- 📤 `export`：把通过所需检查的数据整理为 ZIP 文件，用于交付与归档

👉 全部工具说明详见：[TIDAS 工具包](/zh/docs/tool/tidas-tool-intro/)

## 🔗 集成能力(Features)

TIDAS 已构建多种面向实际场景的集成方案，支持可信计算与数据互操作：

- 🔐 [权限控制（Permission Control）](/zh/docs/integration/tidas-permission-control/)：实现多方协作下的数据访问控制与授权机制

- 🧠 [隐私计算（Privacy Computing）](/zh/docs/integration/tidas-privacy-computing/)：基于多方安全计算与联邦分析实现数据可用不可见

- 🔗 [区块链集成](/zh/docs/integration/tidas-blockchain/)：实现数据不可篡改与分布式验证

- 🤖 [AI 集成（MCP 服务）](/zh/docs/integration/tidas-to-ai/)：集成 MCP AI Server，支持数据语义分析、数据补全与智能验证
